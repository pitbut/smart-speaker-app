# Умная колонка (Smart Speaker)

Автономное Android-приложение — офлайн голосовой ассистент с активацией по кодовому слову.

## Возможности
- **Офлайн-распознавание речи** (Vosk, русская модель) — работает без интернета
- **Кодовое слово** настраивается в Настройках (по умолчанию: «катя слушай»)
- **Команды**: время, дата, погода (город настраивается), таймер («таймер на 5 минут»),
  будильник («будильник на 7:30»), умный дом («включи свет» / «выключи свет» через MQTT)
- **Умный дом**: публикация ON/OFF в MQTT-топик — подключается к любому брокеру
  (Home Assistant, Mosquitto и т.д.), настраивается в Настройках
- Работает в фоне (foreground service), с автоперезапуском при сбоях распознавания

## Как это работает
1. Открой Настройки — укажи город для погоды и, если нужно, MQTT-брокер
   (адрес вида `tcp://192.168.1.10:1883`, топик, логин/пароль).
2. Нажми "Включить" на главном экране.
3. Скажи кодовую фразу (по умолчанию «катя слушай»).
4. После "Да?" произнеси команду.

## Сборка APK через GitHub (без Android Studio)
1. Залей репозиторий в свой GitHub (см. ниже).
2. Вкладка **Actions** — workflow сам скачает офлайн-модель речи (~45 МБ) и соберёт APK
   при пуше в `main`, либо запусти вручную кнопкой **Run workflow**.
3. Зайди в конкретный run → **Artifacts** → скачай `smart-speaker-debug-apk.zip`,
   внутри — `app-debug.apk`.
4. Установи APK на телефон (разреши установку из неизвестных источников).

## Как залить в свой GitHub
```bash
cd smart-speaker-app
git init
git add .
git commit -m "Smart speaker: offline STT, weather, timers, alarms, MQTT"
git branch -M main
git remote add origin https://github.com/<твой_логин>/smart-speaker-app.git
git push -u origin main
```

## Важно (честно о статусе)
Это большой апдейт (офлайн Vosk + MQTT + погода + таймеры/будильники), собранный за один
проход без доступа к Android SDK/эмулятору в моей среде — то есть я не могу локально
скомпилировать и протестировать перед тем как отдать тебе. Основные риски первой сборки:
- Координаты библиотеки MQTT (`com.github.hannesa2:paho.mqtt.android`) — если Gradle
  не найдёт зависимость, напиши мне логи ошибки из Actions, поправлю.
- Vosk API (`org.vosk.*`) — есть небольшой шанс несовпадения версии метода/класса,
  тоже чинится по логам ошибки сборки.
Если первая сборка в Actions упадёт — просто пришли мне текст ошибки (вкладка Actions →
неудачный run → раскрыть шаг с крестиком), я поправлю точечно.

## Локальная сборка в Android Studio (опционально)
Если решишь тестировать локально — скачай и распакуй модель вручную:
```
https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip
```
в `app/src/main/assets/model/` (папка `model` должна содержать файлы модели напрямую).
