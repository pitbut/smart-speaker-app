# ЧистоФон — продвинутая очистка Android

Очиститель памяти телефона уровня CCleaner, но с расширенными возможностями. Kotlin + Jetpack Compose,
Android 8.0+ (minSdk 26, targetSdk 35). Интерфейс на русском, работает полностью офлайн.

## Возможности

| Раздел | Что умеет |
|---|---|
| **Кэш приложений** | Сканирует все установленные приложения. Фильтр **Пользовательские / Системные / Все**, сортировка **по объёму кэша, по имени (А→Я / Я→А), по общему размеру, по дате установки**, поиск. Отдельно показывается **скрытый** (внутренняя память) и **видимый** (Android/data) кэш. «Выбрать все» или по одному. |
| **Видимый кэш** | Мгновенно: Android ≤ 10 — напрямую; Android 11–12 — через доступ к папке Android/data; любой Android — через root. |
| **Скрытый кэш (авто)** | Служба «Спец. возможностей» сама открывает «О приложении → Хранилище» и нажимает «Очистить кэш» для каждого выбранного приложения, с панелью прогресса и кнопкой «Стоп». Поддержка AOSP, Samsung, MIUI/HyperOS (меню «Очистить»), ColorOS и др. Кнопки «Очистить данные/хранилище» **никогда** не нажимаются (проверка опасных фраз). |
| **Системная очистка** | Android 11+: системный диалог «Очистить кэш всех приложений». Root: `pm trim-caches`. |
| **Мусорные файлы** | Временные файлы, логи, миниатюры `.thumbnails`, APK (с пометкой «уже установлено»), кэш-папки в общей памяти, остатки удалённых приложений (Android/data, obb, media), пустые папки, старые загрузки. |
| **Большие файлы** | Порог 10 МБ … 1 ГБ, фильтр по типу (видео, аудио, фото, архивы, APK, документы), сортировка, превью, открыть/поделиться/удалить. |
| **Посторонние папки** | Всё в корне памяти, что не относится к системе Android (не DCIM, Download, Music…), с размером, числом файлов и **определением приложения-владельца**. Папки без владельца — вероятные остатки. Встроенный проводник для просмотра содержимого. |
| **Дубликаты** | 4 режима: **точные копии** (размер → быстрый хэш → полный MD5), **копии медиа** с разными именами, **похожие фото** (перцептивный dHash, настраиваемая чувствительность), **одинаковые имена**. Автовыбор: оставить самый старый / новый / с коротким путём / в DCIM / самый большой. В каждой группе всегда остаётся хотя бы один файл. |
| **Быстрая очистка** | Одна кнопка на главном экране — удаляет безопасный, отмеченный по умолчанию мусор. |
| **Root-режим** | Мгновенная очистка скрытого и видимого кэша, доступ к Android/data на Android 11+. |

## Разрешения

* **Доступ к истории использования** — размер кэша каждого приложения.
* **Доступ ко всем файлам** — поиск и удаление файлов.
* **Спец. возможности** (необязательно) — автоочистка скрытого кэша без root.
* **Папка Android/data** (Android 11–12, необязательно) — мгновенная очистка видимого кэша.

> Ограничение Android: начиная с Android 6 сторонние приложения не могут удалять скрытый кэш других программ напрямую.
> Поэтому без root используется автонажатие через спец. возможности — так же делает CCleaner.

## Сборка

```bash
cd phone-cleaner
./gradlew assembleDebug          # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest      # юнит-тесты
```

APK также собирается автоматически в GitHub Actions (артефакт `PhoneCleaner-debug-apk`).

### Релиз для RuStore

Создайте ключ и файл `phone-cleaner/keystore.properties` (не коммитится):

```properties
storeFile=release.jks
storePassword=...
keyAlias=cleaner
keyPassword=...
```

```bash
keytool -genkey -v -keystore release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias cleaner
./gradlew assembleRelease   # или bundleRelease для AAB
```

При публикации в RuStore укажите в описании, зачем нужны «Доступ ко всем файлам» и «Спец. возможности»
(текст для службы уже есть в `res/values/strings.xml`).
